## Architecture-diagram expansion

The instructor's shared visual brief asks students to distinguish the Transformer block from the complete LLM and to see RAG as an external evidence system. The following diagrams are added as native, labeled HTML/CSS so they remain readable, interactive, and accessible in the delivered player.

| Lesson / destination | Diagram and instructional job | Required labels | Interaction and check | Fidelity risk |
|---|---|---|---|---|
| 19 / tokenization | Tokenizer pipeline: visible string -> subword pieces -> vocabulary IDs -> sequence length. Show that tokens are learned units and IDs are lookup indices, not meanings. | input text, boundary marker, subword token, vocabulary ID, `n` positions | Switch among a common word, an unfamiliar name, and code; predict which creates the longest sequence. | Do not imply one universal segmentation; label examples illustrative. |
| 19 / transformer architecture | One decoder block opened into masked multi-head self-attention, add-and-normalize, feed-forward network, and a second residual path. Show the block repeated `N` times. | input state `X`, Q/K/V, causal mask, attention mixture, residual, normalization, FFN, output state | Select a subsystem and highlight both its input and its instructional purpose. | Preserve decoder-only masking distinction and avoid claiming heads have fixed linguistic roles. |
| 20 / complete LLM | End-to-end autoregressive LLM diagram: prompt -> tokenizer -> token and position embeddings -> Transformer blocks x N -> LM head/logits -> softmax and sampling -> next token -> append and repeat. Visually bracket what is inside the model versus decoding around it. | tokenizer, embeddings, Transformer stack, LM head, vocabulary logits, temperature/top-k/top-p, autoregressive loop | Step through one generated token and identify which components have learned parameters versus runtime state. | Do not equate the Transformer alone with the complete LLM; sampling does not verify truth. |
| 21 / RAG architecture | Dual-lane diagram: offline document ingestion into a searchable index; online question embedding and retrieval; evidence assembled with the question; LLM generates answer with citations. | 22 / evaluation architecture | Instrumented RAG pipeline with measurement probes at corpus, retrieval, context, generation, and product layers.
